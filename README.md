# Somali POS

React + Vite + Tailwind POS application in Somali.

## Sida loo bilaabo
1. Ku rakib Node.js 18+.
2. Terminal ka fur folder-kan.
3. Orod:
   npm install
   npm run dev
4. Fur URL-ka Vite ku siiyo.

## Waxa ku jira
- Dashboard
- Iibka/POS
- Inventory: add/edit/delete
- Cart iyo live totals
- Tax setting
- Checkout + stock deduction
- Customer/debt ledger
- Reports
- Settings
- localStorage persistence
- Printable receipt

Xogta app-ka waxaa lagu kaydiyaa browser localStorage key: `somali-pos-v1`.
